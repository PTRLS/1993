# 1993

Пошаговая пиксельная игра про осень 1993 года: вы — Верховный Совет, удержите Белый дом.

**Играть:** https://ptrls.github.io/1993/ (прямо в браузере, на телефоне тоже; сохранение — в браузере).

## Обновить игру на сайте

Сайт — это файлы из корня ветки `main`, GitHub Pages публикует их сам через минуту после пуша.

```bash
bash tools/update.sh /путь/к/1993-game   # по умолчанию /mnt/project-files/1993-game
git add -A && git commit -m "Сборка 0.XX" && git push
```

`update.sh` копирует `index.html`, `js/`, `css/` и `SOURCES.md`, вырезает подключение музыки
(трек в открытую версию не входит, звуковые эффекты синтезируются и остаются) и вставляет
метатеги превью для Твиттера (`og.png`, 1200×630). Перегенерировать превью: `node tools/og.js`.

## Авторы и лицензии

Код и графика — автор игры. Портреты — обработанные (обрезка, пикселизация, палитра)
фотографии с Викисклада; авторы и лицензии в [SOURCES.md](SOURCES.md). Производные портреты
распространяются на условиях тех же лицензий (CC BY / CC BY-SA соответственно).
